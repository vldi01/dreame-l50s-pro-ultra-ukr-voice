## Що сказано в кожному файлі

`phrases.csv` — один рядок на кожен `*.ogg`.

| Колонка | Зміст |
|---|---|
| `file` | Ім’я файлу, наприклад `7.ogg` |
| `english` | Англійський зміст фрази, якщо він відомий |
| `ukrainian` | Український зміст, якщо він є в спільнотній таблиці |
| `source` | Звідки взято текст |
| `note` | Наскільки підпису можна довіряти |

`source`:

| Значення | Що це | Файлів |
|---|---|---|
| `community` | Англійська і українська зі [спільнотної таблиці](https://github.com/sverdlyuk/glados_ukr) (`dreame_glados_uk_mapping.csv`, колонки змісту, не пародія GLaDOS) | 157 |
| `x50_catalog_en` | Англійський підпис з каталогу X50 Ultra ([dreame-sprachpaket-manager](https://github.com/Anon365-Project/dreame-sprachpaket-manager), `dreamevoice/data/sound_catalog.json`) | 347 |
| `x50_catalog_de` | Англійський переклад німецького ручного підпису з того ж каталогу. Англійською цього рядка там не було | 74 |
| `voice_mapping` | Ця модель грає цей файл замість старого номера. Текст узято зі старого номера | 5 |
| `unknown` | Публічного підпису немає | 27 |

Українською підписано 162 файли. Решта відома лише англійською або ніяк. Підписи з X50 не звірялись на слух з цим паком: номер файлу на іншій моделі інколи означає іншу фразу.

Службові json у `voice/` не є списком фраз. `tts.json` — шаблони складених оголошень (китайська, англійська, німецька, російська, японська), і їхні номери не збігаються з іменами `*.ogg`.
